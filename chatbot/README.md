# デジカレくん（質問チャットボット）

受講生の質問に答えるロボットです。答えられなかった質問は事務局に届き、回答するとロボットが覚えます。

| ファイル | 中身 |
| :- | :- |
| [index.html](index.html) | 見た目の試作。ブラウザで開くだけで動きます（スプレッドシートにはつながりません） |
| [apps-script/Code.gs](apps-script/Code.gs) | 本番の仕組み（答えを探す、AIに聞く、質問リスト、メール、利用料の見張り） |
| [apps-script/Index.html](apps-script/Index.html) | 本番の画面 |
| [apps-script/appsscript.json](apps-script/appsscript.json) | Apps Scriptの設定 |

## しくみ

```
受講生がロボットに質問
 ├ Q&Aに答えがある        → その場で回答
 ├ 個別の相談・急ぎ        → 「事務局に直接連絡してね」とLINEを案内（記録しない）
 └ みんなに関係するが答えがない → 「質問リスト」に記録して、事務局にすぐメール
                                 → 事務局が回答を書き「Q&Aに追加」にチェック
                                 → 次からロボットが答えられる
```

- 「AIを使う」が「オフ」のときは、キーワードで探して答えます（無料）
- 「オン」にすると、AI（Claude Haiku 4.5）がQ&Aの内容だけを使って答えます（有料・少額）
- 予算を超えたとき、クレジットが切れたとき、エラーのときは、自動でキーワード方式に切り替えて、事務局にメールします

## はじめの設定（1回だけ）

### 1. スプレッドシートとApps Scriptを用意する

1. Googleドライブで、新しいスプレッドシートを作ります（名前の例：「デジカレくん」）。**このスプレッドシートは受講生には共有しません**
2. メニューの「拡張機能」→「Apps Script」を開きます
3. 最初からある `コード.gs` の中身をすべて消して、[Code.gs](apps-script/Code.gs) の中身を貼り付けます
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `Index` にして、[Index.html](apps-script/Index.html) の中身を貼り付けます
5. 左の歯車（プロジェクトの設定）→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェックを入れます。表示された `appsscript.json` の中身を、[appsscript.json](apps-script/appsscript.json) の中身に置き換えます
6. 保存（フロッピーのアイコン）を押します

### 2. シートを作る

1. Apps Scriptの上にある関数の選択欄で `setup` を選び、「実行」を押します
2. 「承認が必要です」と出たら、自分のアカウントを選んで許可します
   - 「Googleがこのアプリを確認していません」と出たら、「詳細」→「（安全ではないページ）に移動」を押します。自分で作ったものなので大丈夫です
   - 許可する内容：スプレッドシートの編集、メールの送信、外部（AI）への接続、毎月のタイマー
3. スプレッドシートに「Q&A」「質問リスト」「利用記録」「設定」の4つのシートができます。Q&Aには、チラシの内容から作った8つの質問が入っています
4. スプレッドシートを開き直すと、メニューに「デジカレくん」が出ます

### 3. ウェブアプリとして公開する

1. Apps Scriptの右上「デプロイ」→「新しいデプロイ」を押します
2. 歯車から種類「ウェブアプリ」を選び、次のように設定して「デプロイ」を押します
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**Google アカウントを持つ全員**
3. 表示された「ウェブアプリのURL」をコピーします。ブラウザで開くと、ロボットが表示されます

### 4. Googleサイトに置く

Googleサイトの編集画面で「挿入」→「埋め込む」→「URLで埋め込み」を選び、ウェブアプリのURLを貼り付けます。枠は縦長（高さ600px以上）にしてください。

ここまでで、**キーワード方式（無料）**で動きます。

## AIをオンにする（お金がかかります）

AIの利用料は、Claudeのサブスク（Pro・Maxなど）とは別にかかります。前払いのクレジットを使います。

1. [Anthropicの管理画面（Claude Console）](https://platform.claude.com/) にログインします
2. 「Settings」→「Billing」で、クレジットを少額（$5〜10）購入します
   - **自動チャージ（Auto-reload）はオフ**にします。買った分より多く払うことはありません
   - クレジットは購入から1年で期限切れになり、返金はできません
3. 同じ「Billing」の「Spend limits」で、月の上限を **$2** にします
4. 「API Keys」で新しいキーを作り、コピーします（`sk-ant-` で始まる文字列）
5. スプレッドシートのメニュー「デジカレくん」→「APIキーを登録する」に貼り付けます。キーはシートには保存されません
6. 「デジカレくん」→「AIの接続テスト（約1円かかります）」で、「つながりました！」と出るか確かめます
7. 「設定」シートの「AIを使う」を **オン** にします

## ふだんの運用（事務局）

### 質問が来たとき
「【デジカレくん】新しい質問がきました」というメールが届きます。

1. メールのリンクから「質問リスト」を開きます
2. 「担当」に名前を書き、「状態」を「対応中」にします
3. 「事務局の回答」に答えを書きます
4. 「Q&Aに追加」にチェックを入れます → 回答が「Q&A」シートに移り、「状態」が「回答済み」になります
   - Q&Aに入れない質問は、「状態」を「対応しない」にします

### Q&Aを直す
「Q&A」シートを直接書き換えます。すぐにロボットの答えに反映されます。

| 列 | 書くこと |
| :- | :- |
| 質問 | 質問の例 |
| キーワード | キーワード方式で探すときの言葉（カンマ区切り）。AIのときは使いません。「固まる」より「固ま」のように**言葉の頭の部分だけ**書くと、「固まった」「固まって」にも一致します |
| 答え | ロボットが答える内容。AIはこの内容だけを使って答えます |
| 表示 | 「非表示」と書くと使われなくなります |

### 設定を変える
「設定」シートの「値」を書き換えます。

| 項目 | 内容 |
| :- | :- |
| AIを使う | オン／オフ |
| 月の予算(円) | 50%・80%でメール、100%でAIを止めてキーワード方式に切り替え。翌月1日から戻ります |
| お知らせメールの送り先 | スタッフを増やすときは、カンマ(,)で区切って書き足します |
| LINEのURL | わかったら入れると、個別の相談のときに［LINEで事務局に連絡する］ボタンが出ます |
| AIのモデル・単価 | モデルを変えるときは、Anthropicの料金表に合わせて単価も変えます |

### 届くメール
| 件名 | いつ |
| :- | :- |
| 新しい質問がきました | 答えられない質問が来るたび |
| 今月の予算の50%／80%を使いました | それぞれ月に1回まで |
| 今月の予算に達しました | 月に1回まで（AIは自動で止まります） |
| AIが使えませんでした | クレジット切れ・キーのまちがいなど（同じ内容は1日1回まで） |
| ○月の利用まとめ | 毎月1日の朝9時 |

### コードを変えたとき
Apps Scriptで「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン」を「新バージョン」にして「デプロイ」を押します。URLは変わりません。
