# デジカレ第5期 受講生サイト用 埋め込みパーツ

受講生専用のGoogleサイトに貼り付けて使う、小さな表示パーツです。
事務局がスプレッドシートに1行書くと、サイトの表示が自動で変わります。

| パーツ | ファイル | 表示する内容 |
| :- | :- | :- |
| お知らせ一覧 | [widgets/oshirase.html](widgets/oshirase.html) | 申し込みフォーム・宿題・連絡。締切が近いものは目立たせ、締切を過ぎたものは「受付終了」と表示 |
| 次の講座 | [widgets/tsugi-no-koza.html](widgets/tsugi-no-koza.html) | 次の講座の日時・場所・持ち物と「あと○日」。その下に全回の日程を小さく一覧（終わった回は薄く、次の回に目印） |
| デジカレくんへの質問欄 | [widgets/ask.html](widgets/ask.html) | 質問を書いて「デジカレくんに質問する」を押すと、デジカレくんの画面が開いてその質問が送られる。中の `WEBAPP_URL` にウェブアプリのURL（…/exec）を入れる |
| リンク集 | [widgets/links.html](widgets/links.html) | 区分・グループごとの見出しとボタン。リンクが空欄のボタンは「準備中」 |

ファイルをブラウザで開くと、見本のデータで見た目を確認できます。

質問チャットボット「デジカレくん」は [chatbot/README.md](chatbot/README.md) を見てください。

---

## はじめの設定（1回だけ）

### 1. スプレッドシートを作る

1. Googleスプレッドシートを新しく作り、シートを3つ用意します。シート名は「お知らせ」「講座日程」「リンク集」にします
2. 1行目（見出し）を次のとおりにします。見出しの文字が違うと表示されないので、そのまま写してください。列の順番は入れ替えても大丈夫です
   - **お知らせ**：`掲載日 / 種類 / タイトル / 内容 / リンク / リンクの文字 / 締切 / 表示`
   - **講座日程**：`日付 / 開始 / 終了 / 講座名 / 場所 / 持ち物 / メモ`
   - **リンク集**：`表示順 / 区分 / グループ / タイトル / 補足 / リンク / 表示 / メモ / ボタンの文字`
   - 見本は [sheet-templates](sheet-templates/) にあります（ファイル → インポート で読み込めます）

### 2. シートを「ウェブに公開」する

1. スプレッドシートの「ファイル」→「共有」→「ウェブに公開」を選びます
2. 「お知らせ」シートと「カンマ区切り形式（.csv）」を選んで「公開」を押し、表示されたURLをコピーします
3. 「講座日程」「リンク集」シートも同じ手順で公開し、それぞれのURLをコピーします

### 3. パーツにURLを入れる

各HTMLファイルの上のほうにある次の行の `""` の中に、コピーしたURLを貼り付けます。

```js
const CSV_URL = "ここにURLを貼る";
```

### 4. Googleサイトに貼り付ける

1. Googleサイトの編集画面で「挿入」→「埋め込む」→「コードを埋め込む」を選びます
2. HTMLファイルの中身をすべてコピーして貼り付け、「次へ」→「挿入」を押します
3. 枠の大きさをドラッグで調整します（お知らせは縦長にするのがおすすめです）

### 5. 資格取得のページにもお知らせを置く

お知らせのシートは1つのまま、「種類」が「資格取得」のお知らせだけを資格取得のページに出します。お知らせパーツを2回貼り付け、それぞれ上のほうの設定を次のようにします。

| 貼る場所 | 設定 |
| :- | :- |
| ホーム | `const ONLY_TYPE = "";` ／ `const HIDE_TYPES = ["資格取得"];`（最初からこの設定です） |
| 資格取得のページ | `const ONLY_TYPE = "資格取得";` ／ `const HIDE_TYPES = [];` |

## 事務局の更新のしかた（ふだんの作業）

**スプレッドシートに書くだけです。Googleサイトを開く必要はありません。**
書いてから表示されるまで、5分ほどかかることがあります。

### お知らせを出す

| 列 | 書くこと | 例 |
| :- | :- | :- |
| 掲載日 | 載せ始める日。**未来の日付にすると、その日まで表示されません**（予約投稿） | 2026/11/01 |
| 種類 | 「申し込み」「宿題」「連絡」など。この言葉で絞り込みボタンができます。**「資格取得」と書くと、ホームには出ず、資格取得のページだけに出ます** | 宿題 |
| タイトル | 見出し（必須） | 第1回の宿題 |
| 内容 | 本文。セル内の改行もそのまま表示されます | |
| リンク | フォームや資料のURL（https:// から始まるもの） | |
| リンクの文字 | ボタンに出す言葉。空なら「開く」 | 申し込む |
| 締切 | あれば日付を書く。3日前から赤く目立ち、過ぎたら「受付終了」になり、14日後に一覧から消えます | 2026/11/07 |
| 表示 | 「非表示」と書くと出なくなります（下書きや取り下げに） | |

- 掲載日が新しいものには7日間「NEW」が付きます
- 行を消すと、サイトからも消えます

### リンク集を変える

「リンク集」シート（見本：[sheet-templates/links.csv](sheet-templates/links.csv)）を書き換えます。

| 列 | 書くこと |
| :- | :- |
| 表示順 | 小さい順に並びます。10、20、30…と間をあけておくと、あとで間に入れやすくなります |
| 区分 | 大きい見出し（例：講座期間中、修了後） |
| グループ | 小さい見出し（例：講座の基本、個別フォローアップ、対面講座①） |
| タイトル | ボタンに出す名前（必須） |
| 補足 | ボタンの下に小さく出す説明 |
| リンク | 開くページのURL（https:// から始まるもの）。**空欄だと押せない「準備中」になります** |
| 表示 | TRUE（チェックあり）の行だけ出ます。対面講座の写真やアーカイブは、準備ができたらTRUEにします |
| メモ | 事務局用のメモ。サイトには出ません（ただし公開したシートのURLを知っている人には見えます） |
| ボタンの文字 | 右側に出すボタンの言葉（例：参加する）。空なら「›」。リンクが空欄のあいだは「準備中」の押せない表示になり、リンクを入れるとこの言葉のボタンに変わります |

### 講座日程を変える

「講座日程」シートの日付・時間・場所などを書き換えるだけです。今日以降でいちばん近い講座が「次の講座」に出ます。

## 大切なルール（個人情報）

「ウェブに公開」したシートは、**URLを知っている人なら受講生でなくても見られます**。
そのため、このスプレッドシートには次のことを書かないでください。

- 受講生の名前・連絡先・メールアドレス
- 申し込みフォームの回答
- 公開されて困る情報

申し込みフォームの回答は、これまでどおりフォームの回答用スプレッドシート（非公開）で管理します。
